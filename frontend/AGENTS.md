# AGENTS.md

## Architecture
- Frontend only: talks to the external FastAPI backend via `src/api/` (base URL from `VITE_API_BASE_URL`); never add backend code, mocks, or fake data — the backend is owned by the user.
- Data fetching runs client-side with React Query hooks in `src/hooks/useResearch.ts` (not route loaders) because the backend runs on the developer's machine and is unreachable from SSR.
- Page UI lives in `src/pages/`; route files in `src/routes/` are thin wrappers that set head() and render a page.
- `src/routeTree.gen.ts` is generated by the TanStack Router plugin and must never be edited by hand.
